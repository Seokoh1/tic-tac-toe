# Tic-Tac-Toe

A browser Tic-Tac-Toe game, built incrementally to practice git/GitHub while learning to code with Claude Code.

## Plan

- [ ] Day 1: Static game board (HTML/CSS, 3x3 grid, no logic yet)
- [ ] Day 2: Click handling — alternating X/O placement
- [ ] Day 3: Win detection — rows, columns, diagonals, draws
- [ ] Day 4: "New Game" button + scoreboard
- [ ] Day 5: Polish + deploy live via GitHub Pages

Each day's work is its own small pull request.
